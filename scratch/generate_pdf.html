This is not a technical manual. It is a plain-language operating map that helps the client understand the website as a working business system.

05
ADMIN EDITING GUIDE

This answers: How can the client update the website without accidentally breaking it?

Simple SOP rule

Each instruction should name the exact menu, page, field, button, and final check. Add screenshots beside the steps whenever the interface is not obvious.

Task Steps
Edit homepage copy Go to `src/app/page.tsx` or CMS -> Edit hero headline / copy -> Save file -> Run `npm run build` or push git commit -> Verify live site.
Update Derek AI Persona Go to `knowledge files/` or Admin Portal -> Edit calibration text file -> Re-deploy -> Test Derek response in `/office` chat.
Send Email Newsletter Go to `/admin/email-marketing` -> Click New Campaign -> Enter Subject & Body -> Select Audience -> Click Send via Resend.
Monitor AI Costs Go to `/admin/costs` -> Review daily token spend graphs -> Verify budget guardrail limits ($50/day max) -> Adjust if needed.
Manage Beta Testers Go to `/admin/beta-testers` -> View applicant queue -> Click Approve/Reject -> System sends automated invitation email.
Manage Testimonials Go to `/admin/social-proof` -> Click Add Testimonial -> Enter founder name, photo, quote, rating -> Click Publish.

Every SOP should include

The purpose of the task.
The exact admin area or tool to open.
Numbered steps in the correct order.
Screenshots with correct buttons highlighted.
What should not be changed.
How to preview before publishing.
How to confirm the update worked.
Who to contact when the result looks wrong.

Before making a change (Safe Editing Rules)

Create a backup or git branch when the task affects layout, code, database schemas, integrations, navigation, payments, or API keys. Small content edits should still be previewed on staging before publishing.

Flow 1: User Onboarding & AI Strategy Generation

Onboarding Form Submission

↓
Next.js API Route (/api/questionnaire)
Validates payload, sanitize inputs via DOMPurify.
↓
Google Gemini AI SDK (@google/genai)
Processes prompt with knowledge files calibration & generates executive strategy.
↓
Supabase Database Storage
Stores user profile, strategy blueprint JSON, and initial action steps.
↓
Resend Email Welcome Notification
Automated email dispatched with strategy summary and login magic link.

Flow 2: Pro Tier Subscription & Stripe Billing

Checkout Click on /upgrade
User selects Pro monthly ($49/mo) or annual plan ($490/yr).
↓
Stripe Hosted Checkout Page
Securely handles credit card processing & PCI compliance.
↓
Stripe Webhook Handler (/api/webhooks/stripe)
Receives `checkout.session.completed` & updates user subscription status in Supabase.
